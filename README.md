# Obfuscation project

---

Java tool designed to create Datasets containing obfuscated data starting from Minecraft plugins. The project is intended for research uses.

## Documentation

---

- [Architecture](docs/ARCHITECTURE.md) contains an overview of the structure of the project.

## Instructions

The runConfigurations for IntelliJ IDEA can be found under [runConfigurations](.idea/runConfigurations)

Currently, two configurations are available, one with VERBOSE=true and one without VERBOSE (a missing VERBOSE argument results in a VERBOSE=FALSE).
